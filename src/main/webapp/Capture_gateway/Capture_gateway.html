Processo de Captura da Autorização

Nesta página pode efetuar uma captura de uma transação previamente realizada. Para isso, deve preencher o Transaction ID e o respetivo valor.

Após submeter a captura, será enviada uma requisição para a API:

POST https://spg.qly.site1.sibs.pt/api/v2/payments/{transactionID}/capture


O resultado da operação será apresentado no painel de Debug abaixo. Se a captura for realizado com sucesso, será indicado com uma mensagem de confirmação.

Para informações detalhadas, consulte a documentação oficial:
